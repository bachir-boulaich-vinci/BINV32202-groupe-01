## Architecture du projet

Le projet Gesta est organisé en deux applications TypeScript :

- **Frontend** : React + Vite dans `frontend/`
- **Backend** : Express + TypeScript dans `backend/`
- **Base de données** : SQLite avec `better-sqlite3`

Le flux backend suit cette organisation :

```text
Route Express
  → Controller
  → Middleware d'authentification / autorisation
  → Service métier
  → Repository SQL
  → SQLite
```

Le frontend suit ce parcours :

```text
Page React
  → Hook
  → Service HTTP
  → API Express
```

Pour l’affichage des offres :

1. `App.tsx` rend la route `/offres`.
2. `OffersPage.tsx` utilise le hook `useOffers`.
3. `useOffers.ts` déclenche la requête.
4. `offers.service.ts` appelle `GET /api/offers`.
5. Vite transmet la requête au backend en retirant le préfixe `/api`.
6. `offers.controller.ts` vérifie l’autorisation.
7. `offers.service.ts` applique la visibilité selon le profil.
8. `offers.repository.ts` interroge SQLite.
9. Les résultats sont convertis en DTO puis renvoyés en JSON.
10. Le frontend valide la réponse et `OfferTable.tsx` affiche les offres.
